Send a custom frame (for protocol research)
Slot test: can a custom channel go in any slot?

Writes ONE test channel named "TEST" on CH21 (476.925 MHz, simplex, no tone) into the slot below, then reads that slot and the list back. Your existing channels are not touched. Save a backup first. Delete it afterwards with the second button.

Channel limit test: how many custom channels does this radio hold?

Adds test channels named LIM (for example LIM41, LIM42, on 476.925 MHz) after your existing channels, one at a time, until the radio refuses. Then it deletes only those test channels and reports the limit. Your own channels are not changed, but save a backup first. If the test is interrupted, the second button removes any leftover LIM channels.

Confirmed on a real radio
  • Connecting, and skipping the accept prompt after the first time
  • Reading and writing custom channels (up to 60, packed list C01, C02 … with no gaps)
  • Frequencies, names (GBK), RX/TX tones: CTCSS and DCS
  • Squelch, VOX, bandwidth and busy lockout (radio-wide settings)
  • Name limit: 18 characters (non-English characters count as 3)
  • Device name, Bluetooth name, voice prompts, voice alert, share location, region
Still unknown
  • TX power and power level values
  • Power save mode values
  • "All channels public" flag (isAllPublic)

These show as raw numbers and are kept exactly as the radio stores them.

LITO Config v0.3 beta

An unofficial tool for backing up and programming Beebest LITO UHF CB radios over Bluetooth, from Chrome or Edge on a PC or Android phone. It talks to the radio the same way the official BEEBEST app does; the protocol was worked out from that app and confirmed on real radios.

Not affiliated with or endorsed by Beebest. Use at your own risk, save a backup before writing, and only program channels that are legal where you use them (in Australia: no voice on channels 22 and 23).

Help finish the decoding

A few settings are still raw numbers (TX power, power level, power save; see Protocol status). If you work one out, for example by changing it in the official app and reading it back here:

  • open a pull request on the project's GitHub page (github.com/Felixrising/lito-config), or
  • send what you changed, the old and new values, and the log file from the button below.

Advanced

The log records every message exchanged with the radio since this page was opened. It contains your radios' names, channels and Bluetooth addresses, nothing else.
